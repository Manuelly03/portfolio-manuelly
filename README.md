# Portfólio — Manuelly Fernandes Pinheiro

Site pessoal responsivo feito com HTML, CSS e JavaScript para apresentar a trajetória acadêmica, atividades, projetos e formas de contato.

## Como visualizar
Abra o arquivo `index.html` no navegador.

## Estrutura
- `index.html` — conteúdo e seções do site
- `style.css` — cores, layout e responsividade
- `script.js` — menu móvel e ano automático
- `assets/` — imagens usadas no portfólio
